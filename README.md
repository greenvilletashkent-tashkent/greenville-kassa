# Greenville — касса в облаке

Один адрес, все телефоны видят одни и те же чеки, товары и остатки.
Компьютер магазина включать не нужно.

## Что в папке
- server.js — сервер (Node.js 18+, ничего доустанавливать не нужно)
- public/index.html — сама касса (одним файлом)
- render.yaml — готовые настройки хостинга
- package.json

## Запуск в облаке (Render), 15–20 минут
1. Зарегистрируйтесь на render.com (можно через Google).
2. New → Web Service → подключите папку/архив с проектом.
3. Runtime: Node. Start command: `node server.js`.
4. Тариф Starter (~5–7 $/мес) — на бесплатном сервис засыпает.
5. Disks → Add Disk: имя любое, Mount Path — `/data`, размер 1 ГБ.
   Без диска база пропадёт при обновлении сервиса.
6. Environment → Add Environment Variable:
   `ADMIN_PASSWORD` = ваш пароль администратора (придумайте свой, 8+ знаков).
7. Deploy. Через 2–3 минуты появится адрес вида `https://greenville-kassa.onrender.com`.

## Первый вход
1. Откройте адрес на компьютере.
2. Откроется экран «Первый запуск»: введите пароль из ADMIN_PASSWORD,
   имя (например «Кристина») и логин `admin`. Это и есть администратор.
3. Заведите продавцов: Настройки → Сотрудники → добавить (логин + пароль).
4. На каждом телефоне откройте тот же адрес, войдите под своим логином.
   Меню браузера → «Добавить на экран Домой» — получится иконка как у приложения.

## Как это работает
- Чеки, товары, остатки, клиенты хранятся на сервере (файл в /data).
- Телефон работает и без интернета, а когда связь появляется — досылает чеки.
- Если два продавца одновременно пробьют чек с одинаковым номером,
  сервер выдаст одному новый номер, чек не пропадёт.
- Все входы сохраняются: после перезапуска сервиса заново входить не нужно.
